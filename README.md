# Python Contact Book

A simple command-line contact book program written in Python. It lets you manage a basic list of contacts directly inside your terminal using a quick menu layout.

## Features
* **Add Contacts**: Save names alongside their phone numbers.
* **View Contacts**: See a full list of all your saved contacts.
* **Search Contacts**: Look up a specific phone number by entering a name.
* **Delete Contacts**: Remove old or unwanted entries instantly.
* **Input Cleanup**: Uses `.strip()` to prevent typos, spaces, or empty entries from breaking the menu loop.

## How to Run

1. Open your terminal or command prompt.
2. Navigate to the folder where you saved the file:
   ```bash
   cd path/to/your/folder
   ```
3. Run the script:
   ```bash
   python contact_book.py
   ```

## Requirements
* Python 3 installed on your machine.
